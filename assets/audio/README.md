# Audio assets

Drop these files here (the game runs silently if they're missing, so you can
add them anytime):

| File             | When it plays                  | Suggestion                        |
|------------------|--------------------------------|-----------------------------------|
| `music_loop.mp3` | Looping background music       | Upbeat synthwave / chiptune loop  |
| `hit.wav`        | Correct single-color tap       | Short bright "blip"               |
| `combo.wav`      | Correct 2-color combo          | Punchier, satisfying "chord"      |
| `fail.wav`       | Wrong press / missed tile      | Low buzz / glitch                 |

Royalty-free sources: freesound.org, pixabay.com/sound-effects, incompetech.com.
Keep SFX short (<1s) and normalized so they don't clip.
